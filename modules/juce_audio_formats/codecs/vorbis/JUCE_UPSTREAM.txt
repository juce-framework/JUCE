Upstream: https://github.com/xiph/vorbis
Version:  1.3.7

The libvorbis sources in this directory are from the libvorbis 1.3.7 release,
with the includes rewritten as paths relative to the including file (JUCE
modules have no include directories). lib/ is upstream's lib/, and
include/vorbis/ holds the public headers. libogg, which these sources depend
on, is vendored separately in ../ogg.
